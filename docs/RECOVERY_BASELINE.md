# G1 实机 SLAM 与导航恢复基线

## 范围

只恢复和增强真实 Unitree G1 的建图导航。项目不包含仿真，也不以 PCD 作为 Nav2 地图生产链路。

## 第一里程碑：恢复原效果

1. 电脑通过网线稳定连接 G1，只读接收真实传感器和状态数据。
2. 建立满足 SLAM Toolbox 的 `/scan`、里程计和 TF 链。
3. 通过键盘低速操控 G1，SLAM Toolbox 在线生成二维占据地图。
4. 使用标准 ROS 2/SLAM Toolbox 接口保存地图。
5. 加载保存的地图并建立可靠定位。
6. Nav2 先只规划、禁止真实运动；验证路径和代价地图后再逐级开放实机控制。
7. 在独立安全层保护下完成低速目标点导航。

## 实施原则

- 先只读数据，后 dry-run，最后才允许真实运动。
- 不信任重装前的接口名称、IP、参数和脚本，全部通过当前实机重新确认。
- 优先复用 Unitree、ROS 2、SLAM Toolbox 和 Nav2 的正式接口。
- 新增适配代码必须说明其不可替代性，并配套离线测试或消息级测试。
- 地图、参数、启动命令和验收记录全部版本化；rosbag 和大地图数据不直接提交 Git。
- 开源前移除密码、设备序列号、私网凭据和可识别场地的信息。

## 安全门

- Gate 0：未接机器人也能构建、启动并运行静态检查。
- Gate 1：接机器人后仅允许 ping、SSH 检查和 DDS/ROS 2 订阅。
- Gate 2：运动接口只运行 dry-run，验证限幅和 watchdog。
- Gate 3：人工急停就位，在空旷区域进行单方向低速键盘测试。
- Gate 4：SLAM 建图期间人工键盘操控，Nav2 不拥有运动权限。
- Gate 5：Nav2 只规划并记录候选速度，机器人保持静止。
- Gate 6：短距离、低速、有人监护的 Nav2 实机导航。

任一安全门失败都不能跳级。
